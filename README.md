# Scientific Calculator (Java Swing)

## 📌 Project Description
This project is a desktop-based Scientific Calculator developed using Java Swing. 
It performs both basic arithmetic operations and scientific mathematical functions.

## 🛠 Technologies Used
- Java (JDK 25)
- Swing
- AWT
- Event Handling
- OOP Concepts

## ✨ Features
- Addition, Subtraction, Multiplication, Division
- Sin, Cos, Tan (Degree Mode)
- Square Root
- Logarithm (Base 10)
- Square (x²)
- Clear and Exit
- Modern Dark UI Design

## ▶ How to Run

Compile:
javac ScientificCalculator.java

Run:
java ScientificCalculator

## 📚 Concepts Implemented
- Object-Oriented Programming
- Inheritance
- Interfaces
- Event Driven Programming
- Layout Managers
- Exception Handling
- Java Math Library
